# TVBox 定制源 v1（FongMi 电视版用）

底本：牛虎 `1.json`，2026-11-12 拉取的快照（`niubihu-1.json`，同目录）。
上游当时为 135 站（牛虎 README 写的是 133 站，已更新为 135 站，以实测为准）。

## 定制逻辑

只做一件事：**以用户已验证能用的牛虎为底，把 4K 区提到前面，其余原样保留。**

- 第 1 位：`🐯牛虎 ┃ 豆瓣热播`（首页海报墙），不动。
- 第 2 位：`🐯牛虎 ┃ 配置中心`（csp_Config），不动。**这是扫码绑阿里 / 夸克 / UC 网盘的入口，4K 原画能不能真播就靠它，绝不能删。**
- 第 3–20 位：4K 区，原牛虎 #79–96 共 18 站，**原顺序整体前移，不删、不打散、不移到末尾**：
  玩偶 / 快映 / 木偶 / 闪电 / 蜡笔 / 多多 / 八零 / 虎斑 / 花卷 / 种子 / 指南 / 小丑 / 搬运 / 至臻 / 爱盼 / 移动 / 云搜5 / 找资源。
- 第 21 位起：其余站点全部按牛虎原顺序保留（厂长、嗷呜①–⑩线秒播、独播、爱看、动漫、短剧、采集源、体育、课堂、少儿等）。
- 除站点顺序外，`spider`、`wallpaper`、`logo`、`danmaku`、`lives`、`parses`、`rules`、`doh`、`flags`、`ijk`、`ads` 全部原样保留，不改包名、不加字段。

## 包含什么

- 站点总数：**135 站**（与底本一致，0 站剔除）。
- 4K 站：名字含“4K”的内容站 **16 个**（玩偶、快映、木偶、闪电、蜡笔、多多、八零、虎斑、花卷、种子、指南、小丑、搬运、至臻、爱盼、移动），另加网盘搜索辅助 2 个（云搜5、找资源），4K 区块共 18 站。
- 免登秒播前排：完整保留（厂长、嗷呜①–⑩线、嗷呜瓜子等，开机即点即播）。
- 直播：7 组 `lives` 原样保留（牛虎官方综合等）。
- 解析：10 组 `parses` 原样保留。
- 爬虫：`spider` 原样保留（`easy1008.jar`，gh-proxy 线路）。

## 不含什么（以及为什么是 0 剔除）

- **不含 `http://xhztv.top` 的任何来源。** 全量扫描牛虎底本，0 站含有 `xhztv.top`。之前在用户电视上报 403 的是另外那个独立的 4K小盒子配置文件（`http://xhztv.top/4k.json`），它不在牛虎里，本定制版根本没引用它，所以不存在“从牛虎里剔掉它”这一步。
- **token 依赖的源一个都没删。** 这一点是用户 2026-11-12 明确更正的：夸克等网盘登录不能少。
  - `☁云搜5` 的 ext 是 `http://127.0.0.1:9978/file/tvfan/token.txt+4k|fhd|auto`，**已完整保留**在 4K 区里（第 19 位），没有删、没有移到末尾。
  - `🔍找资源`（同为 csp_PanSou）也保留在 4K 区末尾（第 20 位）。
  - `手机｜推送` 的 ext 里也有本地 token 文件引用，同样原样保留。
  - 4K 区的玩偶 / 木偶 / 至臻 / 蜡笔 / 闪电等网盘源本身也要靠 token 才能播原画（见下节），同样全部保留。
- 以下名字属于那个独立的 4K小盒子文件，不在牛虎底本里：玩偶4K①、盘搜、Up搜、PanSearch、七夜、阿里云盘登录。本定制版不引用那个文件，它们对应的网盘能力由牛虎的 16 个 4K 站 + 云搜5 / 找资源 + 配置中心承担，功能没有丢。
- 其他 http 小站（如采集区的个别 http CMS 地址）未经实测证实已死，且用户已验证牛虎整体可用，本版不擅自删除，留待每周维护时实测后再处理。

## 网盘绑定步骤（想真看 4K 原画，先做这一步）

token 源不是死源，只是没绑网盘时播不了原画。只看普通在线源，不用管这节；要看 4K 原画，按下面做一次就行：

1. 在 TVBox 首页找到第 2 位 **`🐯牛虎 ┃ 配置中心`**，点进去。
2. 屏幕上会弹出二维码，用手机上的**阿里云盘 / 夸克 / UC 网盘** App 扫码授权一次（三个里有哪个绑哪个，不用三个都绑）。
3. 授权成功后，TVBox 本地会生成 token 文件（就是 `http://127.0.0.1:9978/file/tvfan/token.txt` 那个），之后全网盘源通用，不用每次都扫。
4. 再去前面 4K 区点玩偶、木偶、至臻、蜡笔、闪电这些，选带“4K / 原画”的线路播。
5. 如果绑完还是播不了，先看是不是该源本身在维护，再按下面“怎么反馈”告诉我具体是哪个站、什么报错。

注意：没绑网盘时，4K 区里标 4K 的很多只是 1080p 或转码画质，这不是配置坏了，是网盘没绑。

## 成人单独版（adult.json，和主版分开）

成人站**不在**主版 `custom.json` 里。主版 135 站已核对，与成人版没有重合的 api（0 个），想看成人内容时单独切过去，用完切回主版。

- 文件：`adult.json`，共 **28 站**：22 个 type 1（苹果 CMS）+ 6 个 type 3（爬虫）。
- 22 个 type 1 里，20 个来自用户 MoonTV 的成人源（2026-11-05 逐个实测：18 个返回 200 且有结果，白嫖 / 美少女返回 200 但测试关键词无结果仍保留）：白嫖、美少女、辣椒、155、jkun、乐播、小鸡、玉兔、番号、精品、老色逼、鲨鱼、麻豆、大奶子、杏吧、桃花、森林、滴滴、豆豆、黄色仓库；另外 2 个来自 hebijunge `adult.json`（2026-10-15-b1）里不在 MoonTV 清单里的：艾旦、森林(直连)。
- 6 个 type 3 来自 hebijunge `adult_min.json`（2026-09-27-b2）精简版：18AV、 CableAV、Jable、MissAV、Netflav、XOJav。
- `lives` 为空（成人版不要直播），`parses`（10 组）和 `spider` 与主版一致。

### 怎么切换

TVBox 一次只能用一个配置地址，两个版来回切就是换链接：

1. FongMi → 设置 → 配置地址，先把旧地址清空。
2. 粘贴成人版的配置链接，点确定，退出 App 再进一次（防缓存）。
3. 用完想回主版，同样操作：清空 → 粘贴主版的配置链接 → 确定 → 退出重进。

### 注意

- 番号资源是 `http` 明文（原站就是这么给的），个别网络可能像之前 `xhztv.top` 那样拦；其他 27 站都是 `https` 或爬虫类，不受影响。
- 白嫖 / 美少女用的是 `api/json.php` 接口，不是标准 `provide/vod`，能搜能播但分类可能和别的站不一样。
- 6 个 type 3 爬虫站依赖 spider jar 里有对应的 csp 类。如果某站报 ClassNotFound / 加载失败，只影响那一个站，22 个 type 1 CMS 站照常用。
- 成人站不走网盘 token，和 4K 原画的阿里 / 夸克 / UC 绑定是两回事，不用为成人版再绑网盘。
- 没复制 hebijunge `adult.json` 后半段的大量 XBPQ 站：它们多依赖外部 ext 文件和相对路径 jar（`./deps/...`），脱离原仓库无法独立工作，且同一域名反复出现，复制过来反而容易挂。

## 怎么填进 TVBox（FongMi 电视版）

现在这个 `custom.json` 还在工作目录里，还没有配上线地址。等配置链接发给你之后：

1. 打开 FongMi → 设置 → 配置地址。
2. 把配置链接粘贴进去，点确定。
3. 回首页等加载出来，先看第 1 位是不是豆瓣热播墙、第 2 位是不是配置中心、第 3 位起是不是玩偶 / 快映这些 4K 站。
4. 如果之前填过别的配置，先把旧配置地址清空、退出 App 再进一次，避免缓存的 403 还在。

## 以后维护方式

- 每周检查一次：对照牛虎上游更新，死链替换、新增好源补进对应分区，4K 区和配置中心的位置不动。
- 配置链接固定不变，更新后重启 TVBox 就能拉到新版，不用重新填。
- 哪个源点不动了，直接告诉我是哪个站名、什么报错（403 / 加载失败 / 播不了是三种不同问题），我按这个定位修，不再整条换链接。
- 底本快照 `niubihu-1.json`、构建脚本 `build_custom.py` 都留在同目录，下次维护时用新快照做 diff，避免凭印象改。
